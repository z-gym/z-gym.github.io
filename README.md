# Z Gym

Página web informativa del gimnasio Z Gym, en Posadas, Misiones.

Está hecha con HTML, CSS y JavaScript simples. No necesita instalar nada para funcionar.

Página publicada: https://z-gym.github.io/

## Qué hay en esta carpeta

- `index.html`: toda la página (textos, diseño y funcionamiento).
- `assets/`: las fotos del gimnasio.

## Cómo actualizar la página

1. Cambiá lo que necesites en `index.html` (un horario, un texto) o reemplazá una foto dentro de `assets/`. Si cambiás una foto, dejale el mismo nombre.
2. Abrí una terminal en esta carpeta y ejecutá estos tres comandos, uno por uno:

```
git add .
git commit -m "Describí acá qué cambiaste"
git push
```

3. Esperá 1 o 2 minutos. GitHub publica el cambio solo. Si no lo ves, actualizá la página con Ctrl + F5.
